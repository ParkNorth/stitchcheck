## Unit / naming checks

- "HD" is the Heavy Duty series name, not a rating. "5000" ranks the model within the HD line by feature set only; body, speed and feed are shared with the HD3000.
- Throat: not published.
- Speed: 860 spm in dealer copy; no Janome figure captured.
- "Sews 12 layers of denim" is a dealer title (Linda's Quilt Shoppe), not a Janome spec.

## Owner themes (paraphrase + attribute)

1. A ten-month owner calls it a great basic garment machine bought for about $400 and recommends it. (owner: https://sewing.patternreview.com/review/machine/7293)
2. An upgrade thread praises it at about $499, noting the extra presser foot notch for thick fabric and 18 mechanical stitches. (owner: https://sewing.patternreview.com/SewingDiscussions/topic/126098)
3. HD series buyers ask which model is worth it; replies frame the HD5000 as the same core machine with more stitches, wider zigzag and a quilting kit. (owner: https://sewing.patternreview.com/SewingDiscussions/topic/112978)

## Cross-shop set

1. `janome-hd3000`: same body for about $100 less.
2. `singer-4452`: faster, more stitches, cheaper, lighter build.
3. `brother-st371hd`: 37-stitch metal-frame rival at a lower price.

## Editorial angle

For a buyer choosing between the HD3000 and HD5000; settles whether 0.5 mm of zigzag, a needle threader and seven feet are worth about $100 on the same 860 spm body.
